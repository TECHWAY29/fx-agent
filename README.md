# VaultX FX Agent — React MVP

Premium React/Vite JavaScript frontend based on the supplied FX/Crypto Exchange Platform PRD.

## Run
npm install
npm run dev

## Current frontend scope
- Premium responsive landing page
- Live-style buy/sell rate presentation
- Interactive USDT/NGN calculator
- Guided exchange flow
- Unique order reference generation (frontend demo)
- Order tracking UI
- Admin-ready visual language and component structure

## Next production steps
Connect the forms/rates/orders to the backend API, persist order references, implement admin authentication, receipt upload, bank-account configuration, rate management, and real order lifecycle transitions.
